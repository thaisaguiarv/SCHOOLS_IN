# SCHOOLS_IN
PROJETO DE SISTEMAS INTERATIVOS Jogo: SCHOOLS IN
Desenvolvimento de um jogo digital de plataforma bidimensional (2D) intitulado 'SCHOOLS IN'. O jogo funciona como uma metáfora interativa e lúdica da jornada acadêmica, onde o protagonista deve superar os obstáculos físicos e representativos do cotidiano estudantil para alcançar o seu destino final: a universidade.
